# Slavic Village Tycoon

A survival and strategy simulation game set in a Slavic mythology-inspired world.

## About the Game
You manage a growing village while interacting with mythological spirits such as:
- Leshy (forest spirit)
- Domovoy (house spirit)
- Vodyanoy (water spirit)
- Baba Yaga
- Poludnitsa
- Firebird

Each choice affects:
- Resources (food, water, wood)
- Population growth
- Village rating with spirits

## Features
- Dynamic day/night cycle
- Random mythological encounters
- Resource management system
- Building mechanics
- Win/lose conditions
